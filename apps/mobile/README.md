# HimBazaar Mobile (`himbazaar_mobile`)

Native Flutter app for Android & iOS — **not** a WebView wrapper.

## Stack

- Feature-first / clean architecture
- Riverpod
- GoRouter
- Dio (API-ready)
- Freezed / json_serializable (models)

## Setup

Requires Flutter SDK:

```bash
cd apps/mobile
flutter pub get
flutter run
```

## Current phase

UI foundation + routing + theme + mock-ready services. No real backend auth/payments yet.
